# Yayra v1.0.75 — selectable text and contextual actions

Released: 2026-10-21

## Correct text pointer and highlighting

- Restores the operating system's native text I-beam over actual readable text
  when Yayra or High-visibility pointer themes are active. Links, buttons, and
  other controls keep the hand cursor; blank page space keeps the arrow.
- Uses glyph-level caret hit-testing rather than guessing from an element tag,
  including Electron child frames and Android native website views.
- Enables drag and touch/long-press selection before the native gesture begins,
  including text whose surrounding page chrome normally suppresses selection.
- Keeps text inputs, textareas, and editable regions on the native I-beam at
  every pointer size.

## Highlight actions

- Highlighting text in Yayra pages, settings, document surfaces, or Electron
  website views now opens a compact, non-modal action bar beside the range.
- Read-only text offers **Copy**, **Search**, and **Ask Yayra AI**. Editable
  text adds **Cut** and **Paste** with exact range replacement.
- Clicking anywhere outside the bar closes it without swallowing that click;
  Escape, blur, scroll, navigation, and shell teardown also clean it up.
- Android website views retain the platform selection handles and native
  contextual action mode after Yayra enables the selected text.
- Search and Ask AI open in a fresh tab and preserve private mode. Selected
  text remains inside the page unless the user explicitly chooses an action;
  website selections never cross Electron IPC.
- Password/non-text fields and oversized selections are not read by the action
  bar. Clipboard failures fall back safely to the normal keyboard shortcut.

## Included platform and document work

This build also includes the v1.0.74 provider-compliant Google authentication,
website recovery, visible document Download/Print actions, first/current
presentation semantics, compact PowerPoint controls, free tab reordering, and
downward tab detachment described in [the v1.0.74 notes](v1.0.74.md).
