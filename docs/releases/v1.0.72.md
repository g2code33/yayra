# Yayra v1.0.72 — Full-screen PDF presentations

Released: 2026-10-21

## PDF presentation mode

- Adds **Present** to the integrated PDF toolbar. `F5` presents from page 1 and `Shift+F5` presents from the current page, matching the PowerPoint workflow.
- Uses the same dedicated, projector-ready full-window/fullscreen surface as PowerPoint, with previous/next, direct page jump, page navigator, black/white screen, laser pointer, pen, shortcut help, fullscreen/window switching, and Exit.
- Moves the live PDF.js document into the projector instead of reloading it, rasterizing it into screenshots, or sending it to a conversion service. Selectable text and the original live page canvas remain intact.
- Shows exactly one PDF page at a time, preserves its proportions, and re-fits each page when mixed portrait/landscape dimensions change. Extra-tall pages can scale below the normal reader’s 50% zoom floor only while presenting.
- Supports presentation keys, click, swipe, and throttled wheel navigation: arrows, Page Up/Down, Space, Enter, Backspace, Home/End, `N`, `P`, number + Enter, `F1`, and Escape.
- Restores the same live continuous reader, current page, zoom mode, reading position, night/rotation state, and keyboard focus after exit. PDF mode does not display a fake speaker-notes control.
- Browser/OS Escape from true fullscreen ends the show cleanly; the intentional **Window** action keeps the full-window presentation running.

## Related Documents improvements

- Adds practical file-size ranges to the Documents hub and **Settings → Documents**.
- Separates the sort field from ascending/descending direction, so date, name, type, size, and opening-frequency sorts all work in either direction.
- Keeps legacy combined sort preferences compatible when upgrading.

## Validation coverage

- Adds rendered integration coverage proving that the live PDF.js page tree moves into the projector, only the current page remains visible, presenter tools work, and continuous reading is restored without a reload.
- Adds controller coverage for mixed page proportions, projector-only low-scale fitting, and restoration of the normal reader zoom floor.
- Extends the explicit document capability registry and shared presentation-shortcut contract to PDF without changing PowerPoint speaker notes or embedded-media behavior.
