# Yayra v1.0.74 — Secure Google sign-in, resilient browsing, document actions, and detachable tabs

Released: 2026-10-21

## Website recovery instead of blank pages

- Replaces failed native, Android, and web website surfaces with a first-party browser-style recovery page that explains the connection problem, keeps the requested address visible, provides troubleshooting steps, exposes the Chromium-style error name, and offers an immediate retry.
- Retains failure state per tab without navigating to an internal error URL, so the original URL, history, profile, cookies, and live website engine remain associated with the tab.
- Retries only the active failed site with bounded backoff (1.5 seconds through a 30-second ceiling) and a 20-second attempt watchdog. Healthy loaded pages and failed background tabs are never refreshed by connectivity events.
- Reloads the active failed site immediately when the device comes back online. Electron and Android retry the retained URL explicitly, including failures where the engine never committed the destination and a normal `reload()` could otherwise target the previous page or `about:blank`.
- Keeps the recovery page visible over hidden retry surfaces until the native/Android engine reports a positive main-frame completion or the web frame paints successfully. Failed attempts continue retrying until success, navigation, tab close, or teardown cancels them.
- Adds Android main-frame failure/success events and an Electron success signal gated against `did-fail-load`; neither `did-stop-loading` nor Chromium's completed error document is treated as proof of success.

## PowerPoint toolbar polish

- Makes the PowerPoint identity and control rows substantially shorter so the slide receives more vertical space.
- Gives the dark three-dot menu an explicit high-contrast foreground in every app theme.
- Removes native `title` bubbles from overflow actions—the long tooltip no longer covers neighboring actions—while preserving full accessible explanations through ARIA labels.
- Keeps Desktop app, Close presentation, notes colour, search, slide controls, and presentation mode fully available while the primary actions become easier to reach.

## Document actions and presentation semantics

- Adds visible **Download** and **Print** controls to every integrated PDF,
  PowerPoint, Word, spreadsheet, image, and text viewer.
- Saves downloads as an exact byte-for-byte copy through the native Save dialog
  (or a Blob download on web/PWA); document-tab `Ctrl+S` uses the same path and
  **Desktop app** remains a separate action.
- Prints the complete PDF or PowerPoint file rather than only the currently
  materialised page/slide. PowerPoint creates and cleans up a temporary
  print-only full deck so normal lazy rendering and media stay fast.
- Makes the top PowerPoint **Present** action and `F5` start at slide 1. The
  lower **From current slide** action and `Shift+F5` begin at the selected
  slide; PDF provides the equivalent current-page action.

## Tab movement and new windows

- Keeps horizontal pointer dragging as free tab reordering.
- Detaches an HTTP(S) site into a new Yayra window when its tab is deliberately
  dragged below the tab strip, preserving its current URL, profile, and private
  state and closing the source tab only after handoff succeeds.
- Adds **Move Tab to New Window** to the website-tab context menu as an
  accessible alternative. Document and internal Yayra tabs are never silently
  detached because their in-memory bytes/state cannot be transferred safely.

## Provider-compliant Google authentication

- Moves Yayra's desktop Google identity consent to the OS default browser with
  Authorization Code + PKCE, random state, and a one-shot loopback callback;
  the former app-controlled Google `BrowserWindow` path is removed.
- Intercepts exact Google OAuth and interactive Account sign-in routes before
  Electron/Android embedded website engines load them. Gmail, Google Account,
  and third-party Google sign-in can continue in the secure system browser
  without the embedded-browser rejection, while the Yayra source tab/history
  stays unchanged and browser cookies are never copied.
- Repairs Google's exact embedded-browser rejection route to a clean HTTPS
  `ServiceLogin` entry point with only a bounded HTTPS continuation. Search,
  Gmail content, account management, logout, and unrelated Google navigation
  are not broad-matched.
- Keeps app OAuth separate from Google website sessions and never sends bearer
  tokens through `yayra://` or `com.yayra.app:`. Mobile custom callbacks reject
  token fields, duplicate/lookalike callbacks, wrong state, and oversized input.
- Hardens the Cloudflare Worker exchange with exact CORS origins,
  Origin-to-redirect binding, JSON/body/field bounds, unknown-field rejection,
  auth-specific rate limiting, sanitized profile output, and `no-store`
  responses. Web/PWA pending PKCE transactions are single-use and expire.
- Escapes and validates Google/profile values before account/avatar HTML
  rendering, preventing stored profile markup or unsafe image URLs from
  becoming executable UI.

## Regression coverage

- Covers native offline failure rendering, URL retention, immediate online recovery, duplicate-attempt prevention, background/healthy-tab isolation, stale timer cancellation, web/PWA hidden retries, and positive success teardown.
- Pins Electron’s explicit retained-URL retry IPC and separate success event, Android failure/success lifecycle events, capped retry delays, and cleanup on navigation.
- Verifies PowerPoint overflow contrast, tooltip removal, accessible labels, compact toolbar geometry, exact-byte download/`Ctrl+S`, visible cross-format actions, full-deck print cleanup, and first/current presentation semantics while retaining the existing complete PPTX/PDF document suite.
- Covers horizontal reorder preservation, intentional downward tear-off, gesture cleanup, context-menu handoff, URL/private/profile payloads, source-close-after-success, native bridge wiring, and browser fallback.
- Covers exact Google route classification, rejection repair, direct/redirect/popup system-browser handoff, auth-URL IPC redaction, browser-launch failure, loopback response headers/history cleanup, PKCE/state expiry, token-bearing deep-link rejection, strict Worker CORS/body validation, and profile-markup escaping.
