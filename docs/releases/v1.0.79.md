# Yayra v1.0.79 — consistent file actions and safer site rendering

Released: 2026-10-22

## Consistent file actions

- PDF, PowerPoint, Word, spreadsheet, image, text, and original-file fallback
  viewers now share the same three-dot **More** menu.
- **Desktop app** and each format's **Close** action remain available without
  crowding the primary Download, Print, and Present controls.
- The shared menu preserves keyboard, Escape, accessibility, focus, and
  high-contrast behavior across light and dark viewer themes.

## Website rendering compatibility

- Failed logos, thumbnails, and card artwork can no longer recolor a distant
  viewport-sized app shell.
- Bright or saturated browser `theme-color` values are no longer promoted to
  full-page image fallback colors, preventing false brand-colored page surfaces.
- Narrowly proven full-screen decorative backdrops retain safe dark fallback
  recovery, while authored website themes and dynamic gradient-text repair stay
  intact.

- Application version: **1.0.79**
