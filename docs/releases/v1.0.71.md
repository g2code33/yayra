# Yayra v1.0.71 — Documents hub and projector-ready PowerPoint shows

Released: 2026-10-21

## Documents hub

- Adds a dedicated **Documents** toolbar button directly beside **Downloads** and a first-class `yayra://documents` library.
- Every file explicitly opened through the desktop picker is catalogued, including unknown formats and supported files above the 300 MB internal-viewer ceiling. OS **Open with Yayra** and Downloads **Open in Yayra** feed the same library.
- The hub supports filename/type search; opening-date, file-family, and practical size-range filters; independent ascending/descending sorting by date, name, type, size, or opening frequency; indexed-size/availability summaries; and direct reopen.
- Supported PDF, PPTX/PPTM, DOCX, spreadsheet, image, and safe-text families reopen in Yayra. Unknown formats open unchanged in their system application rather than being misrepresented as renderable.
- Missing or moved sources are identified explicitly. **Locate…** reconnects an existing history row to a user-selected source; **Show**, **Desktop app**, per-row Remove, Remove unavailable, and Clear history are functional.
- Clearing/pruning metadata never deletes, moves, rewrites, or uploads original files.
- Web/PWA/Android picker and drag/drop files receive an honest session catalog. If browser filesystem access is gone after the active tab closes, the entry says it is unavailable instead of claiming persistent access.

## Privacy and Settings

- Adds `electron/documentLibrary.cjs`, a trusted main-process catalog persisted under Electron user data.
- Filesystem paths stay in the trusted main process. Renderer state receives only random opaque ids, basenames, safe metadata, and bytes for one explicitly requested supported file.
- Every reopen re-resolves its opaque id, stats the source, checks permissions and availability, and reapplies the 300 MB internal-viewer limit.
- Adds **Settings → Documents** with default sort field/direction and type/date/size filters, metadata retention, missing-file visibility, slideshow fullscreen/control behavior, and history-management actions.

## PowerPoint presentation mode

- Moves PPTX **Desktop app / Download original** and **Close presentation** out of the primary toolbar and into an accessible three-dot presentation menu. **Present from beginning** lives there too.
- Adds a dedicated black full-window slideshow surface with true browser/Electron fullscreen for projector use; it remains a usable full-window show when fullscreen permission is unavailable.
- Moves the existing PPTX DOM/controller into presentation mode so slide fidelity, lazy images, embedded videos, poster frames, native media controls, notes colour, and original-file safety remain intact.
- Adds auto-hiding projector controls for previous/next, slide-number jump, speaker notes, blank screen, laser pointer, pen, all-slides navigator, shortcut help, fullscreen, and exit.
- Speaker notes start hidden for a clean projector surface and can be toggled during the show. The normal viewer's prior notes and zoom state are restored on exit.
- Adds PowerPoint-style `F5`/`Shift+F5`, arrows, `N`, `P`, `H`, Space, Enter, Backspace, Page Up/Down, Home/End, number+Enter, black/white screen, pointer/pen, navigator, help, and Escape shortcuts.
- Embedded video/audio elements retain their own keyboard and pointer controls. Swipe, click, and wheel slide navigation avoid stealing input from media.
- Presentation ink is a separate, non-destructive layer and never changes the original PPTX.

## Related fixes and validation

- Unknown browser-selected/dropped files now receive the safe original-file fallback and appear in Documents rather than being silently refused.
- Desktop-app actions for catalog-backed tabs open the real original source instead of manufacturing a temporary duplicate.
- Added deterministic tests for opaque-id/path isolation, all-file routing, relinking, availability checks, retention, non-destructive clear, document-hub wiring, PowerPoint shortcuts, projector fullscreen, overflow controls, speaker notes, and media keyboard ownership.
- Updated the document workspace security, lifecycle, all-file, and slideshow architecture contract.
