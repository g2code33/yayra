# Yayra v1.0.73 — Complete PowerPoint body and equation rendering

Released: 2026-10-21

## PowerPoint fidelity

- Restores paragraphs, bullets, equations, explanatory text, pictures, and other slide shapes stored inside OOXML markup-compatibility (`mc:AlternateContent`) branches instead of showing only the title.
- Traverses compatibility content inside ordinary slides and nested groups, including identity groups whose producer legitimately omitted a group transform.
- Reads PowerPoint 2010+ `a14:m` Office Math (OMML) at paragraph level and converts fractions, superscripts/subscripts, radicals, delimiters, operators, limits, accents, equation arrays, and matrices into local semantic MathML. The package never leaves the device.
- Retains each equation’s plain-text fallback for search, copy, extraction, and accessibility while using the structural MathML for the visible formula.
- Preserves compatibility fallback pictures when Yayra cannot understand a modern branch, including picture fills stored in a normal shape rather than `p:pic`.

## Correct slide-footer geometry

- Completes the OOXML placeholder chain from slide master through slide layout to slide. Position, size, vertical anchor, list defaults, and text style now inherit at every level.
- Matches placeholders by type plus index, index alone, and type fallback so third-party exporters that omit the type still resolve correctly.
- Places slide-number fields using their authored master/layout transform at the lower-right instead of the generic upper-left fallback.
- Supplies a safe lower-right slide-number fallback and resolves an empty cached slide-number field from the current local slide number.

## Regression coverage

- Adds a compatibility-heavy PowerPoint fixture with a shape-level compatibility wrapper, a transform-less group, nested run-level OMML, explanatory bullets, a fallback picture, and a slide number whose geometry exists only on the master.
- Verifies native MathML fraction/subscript output, complete body/search text, correct master-inherited title/footer coordinates, and rendered DOM output.
- Keeps existing thumbnails, notes, presentation mode, search, lazy media, video, tables, and document-reader behavior covered by the complete suite.
