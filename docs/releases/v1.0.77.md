# Yayra v1.0.77 — resilient website gradient text

Released: 2026-10-21

## Gradient text remains readable

- Third-party headings built with `.gradient-text` or Tailwind-style
  `bg-clip-text text-transparent` no longer disappear while their background
  gradient paints a large solid rectangle.
- Yayra now applies both standard and WebKit-prefixed `background-clip: text`
  declarations and verifies the renderer's computed result.
- If the website engine cannot accept text clipping, Yayra removes only the
  destructive text gradient and restores a solid foreground selected from the
  inherited site colour or a contrast-safe black/white fallback.
- The repair is narrowly limited to transparent, gradient-backed elements with
  explicit text-clipping intent. Opaque gradient panels, ordinary transparent
  utilities, icons, masks, and decorative overlays remain site-owned.

## Dynamic and cross-platform behavior

- A bounded, debounced observer follows client-rendered elements and later
  class/style transitions without requiring a page refresh.
- Electron website views and Android native tab WebViews use the same
  prefixed-clip-first, readable-solid-fallback behavior.
- Regression coverage includes standard support, prefixed-only support,
  unsupported engines, dynamic transitions, normal opaque gradients, and
  legitimate transparent decorative content.
