# Yayra v1.0.80 — local Office 97–2003 viewing (superseded)

Status: not published as a standalone release. This work is included in the
combined v1.0.81 release; see `v1.0.81.md`.

## Word and PowerPoint 97–2003

- Binary `.doc` and `.ppt` files now open meaningfully inside Yayra instead of
  landing on the unsupported-format screen.
- Yayra parses each file locally, creates a temporary macro-free DOCX/PPTX
  viewing copy in memory, and reuses the established Word and PowerPoint
  controls for layout, tables, search, zoom, notes, thumbnails, printing, and
  presentation mode.
- Conversion runs in a short-lived same-origin Worker where available, with
  cancellation and timeout handling so a damaged document cannot leave a tab
  pretending to load forever.
- The UI labels the temporary local viewing copy honestly and reports parser
  simplifications without claiming perfect legacy fidelity.

## Excel 97–2003 and safer routing

- Existing bundled SheetJS support for binary `.xls` workbooks is now an
  explicit first-class route with sheets, cell search, print, and unchanged
  download behavior.
- Compound File Binary directory sniffing distinguishes Word (`WordDocument`),
  PowerPoint (`PowerPoint Document`), and Excel (`Workbook`/`Book`) streams even
  when a filename or MIME type is misleading.
- Unknown compound containers fail closed to the original-file fallback rather
  than being trusted as a document merely because of their extension.

## Original-file guarantee and offline packaging

- Source bytes are never transferred to the converter Worker directly, never
  uploaded, and never replaced; Download, Desktop app, and the Documents library
  always retain the exact selected file.
- The legacy engine, Worker, license notices, and generated hashes are included
  in PWA precache and Electron packaging checks.
- Linux Open With metadata now advertises the modern and legacy Office formats
  that Yayra can actually open.
- Synthetic, reproducible DOC/PPT/XLS fixtures cover routing, conversion,
  rendering, search/navigation, corruption/password errors, worker isolation,
  and byte preservation.
