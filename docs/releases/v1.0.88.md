# Yayra v1.0.88 — Open English WordNet download pack

## Updates

- Added Open English WordNet 2025 as a second downloadable General English pack alongside Princeton WordNet 3.0. The verified core edition contributes 107,519 synsets and 127,311 indexed terms, with usage examples; it intentionally excludes proper names.
- Included the complete Open English WordNet CC BY 4.0 and underlying Princeton WordNet 3.1 notices in the pack and linked license file. The pack is downloaded only on request and supports offline lookup after installation.
- Generalized pack-install progress and license-link text for multiple datasets, and increased the license-notice allowance so imported packs can retain complete terms.
- Kept detailed source/integrity provenance in pack management, not normal dictionary result cards.
