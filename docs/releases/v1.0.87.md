# Yayra v1.0.87 — Dictionary result and selection polish

## Updates

- Simplified dictionary result cards while keeping source and licensing details in pack management.
- Save and Star controls now show persistent active states. Comparison supports either one word from two dictionaries or two words from one query.
- Moved Highlight into the selected-text actions and added Dictionary to the main menu.
- Added a reviewed dataset/licensing guide. No new corpus is advertised until its edition, redistribution terms, and reproducible pack are verified.
- Google OAuth denials now explain the Google Cloud test-user remedy; app testing restrictions still require consent-screen configuration by the OAuth project owner.

## Validation

- `npm run version:check`
- `npm run lint`
- `npm run typecheck`
- `node --test tests/dictionary-*.test.mjs`
- `npm run build:web --ignore-scripts && node scripts/verify-pwa.mjs`
