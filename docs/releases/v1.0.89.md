# Yayra v1.0.89 — dictionary packs and mini-window handoff

## Updates

- Added GCIDE 0.54 as a General English dictionary pack (114,757 terms), plus separate historically tagged medical (5,761 terms) and pharmacy (61 terms) subsets. Pack management includes the upstream source pin, attribution, GPL-3.0-or-later notice, integrity, and honest scope disclaimers; none are current clinical or drug references.
- Added the FIBO Q2 2026 finance/business terminology pack (2,667 defined terms) with its pinned source, MIT notice, attribution, and no-endorsement/scope notice.
- Added Dictionary to the browser side drawer and the floating mini toolbar. Spaced the pack source/licence links for readability.
- Added “Open in mini yayra” to eligible tab right-click menus. Handoffs are validated in the main process and queued by preload until the mini shell is ready; private tabs are excluded.
- Isolated mini-window session snapshots and close-session choices from the main browser within the same profile.
- Kept the mini toolbar's bookmark, Downloads, Documents, Dictionary, and menu controls fixed while allowing the address/search field to shrink.
- Increased the dictionary license-notice limit so complete upstream notices (including GCIDE's full GPL text and source notices) can be imported without truncation.
