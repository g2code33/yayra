# Yayra v1.0.59 — Google tools menu and built-in PDF reader

## Fixed

- Restores the white Google **+** menu by isolating its semantic sections from legacy page-card CSS.
- Removes the oversized native URL tooltip from recent-tab rows while preserving accessible URL labels.
- Keeps recent-tab selection, Add images, Add files, Create images, and Canvas actions working inside the Google menu.
- Fixes the installed desktop PDF reader startup by serving bundled `.mjs` files with a deterministic JavaScript MIME type under `yayra://`.
- Preserves PDF retry, find, zoom, page navigation, document controls, downloads, and safe Desktop app fallback behavior.

## Release safeguards

- Desktop runtime diagnostics parse a real one-page PDF through the packaged PDF.js engine and module worker on Linux and Windows without letting runner display/console quirks discard otherwise verified installers.
- Web, PWA, and desktop `app.asar` packaging checks gate releases on the lazy PDF.js engine and worker assets being present and complete.
- Development preview styling now follows the production stylesheet order so menu regressions cannot be hidden in local testing.
